# dev_flutter_test

One test suite for the Dart VM, the browser and Flutter: the `flutter_test`
implementation of [dev_test](https://pub.dev/packages/dev_test), and the same
tests as an interactive menu app on a device.

* [dev_flutter_test](dev_flutter_test): the package (getting started in its
  README).
* [examples/dev_flutter_test_example](examples/dev_flutter_test_example): a
  menu app (`flutter run`).

## Setup

pubspec.yaml:

```yaml
dev_dependencies:
  dev_flutter_test:
    git:
      url: https://github.com/tekartik/dev_flutter_test
      path: dev_flutter_test
```
